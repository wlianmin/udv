# Universal Data Viewer

一个在浏览器中运行的 JSON/CSV 数据查看与可视化工具。

数据仅在本地浏览器中处理，不会上传到服务器。

## 在线使用

[点击在线使用](https://wlianmin.github.io/udv/)

## 使用说明

1. 点击或拖放一个 `.json` 或 `.csv` 文件；
2. 如果 JSON 中包含多个数据集，选择需要查看的数据集；
3. 在数据预览中选择需要显示的字段；
4. 选择图表类型并配置字段；
5. 点击“生成视图”查看结果；
6. 可下载 PNG 图表或导出配置 JSON。

## 支持的图表

- 折线图
- 柱状图
- 散点图
- 饼图
- 数据表

## 注意事项

- 仅支持 UTF-8 编码的 JSON 和 CSV 文件；
- 单个文件大小不能超过 20 MB；
- 数据仅在本地浏览器中处理，不会上传到服务器；
- 刷新或关闭页面后，当前数据不会保留。
